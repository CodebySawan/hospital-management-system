Hospital Management System where:
- patients can book appointments
- doctors can manage appointments
- admin can manage users

-------------------------------------------------

v1 features:
AUTH
- register
- login
- JWT authentication

PATIENT
- add patient
- update patient
- view patient

DOCTOR
- add doctor
- view doctor

APPOINTMENT
- book appointment
- cancel appointment
- view appointments

-----------------------------------------------

Roles and Permission:
ADMIN
- manage doctors
- manage patients

DOCTOR
- view appointments

PATIENT
- book appointments
